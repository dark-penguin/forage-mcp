- [ ] 2.2 Implement `logging.go` with an `InitLogging(level slog.Level)` function that configures `slog` to use a text handler writing to `os.Stderr`, and verify a unit test confirms log output goes to stderr (not stdout) by capturing both streams and asserting stdout is empty after a log call
- [ ] 2.3 Implement `main.go` entry point that calls `LoadConfig()`, exits with non-zero status and an error message if config fails, calls `InitLogging()`, registers the two MCP tools, and starts the stdio server loop; verify by running the binary without `FORAGE_URL` set and confirming it exits non-zero with a clear error, and by running it with `FORAGE_URL` set and confirming it stays alive reading stdin

## 3. Forage HTTP client

- [ ] 3.1 Implement `client.go` with a `ForageClient` struct wrapping `*http.Client`, a base URL, and an optional API key; implement a `doRequest(ctx, method, path, body, extraHeaders)` helper that sets `Content-Type: application/json`, adds `Authorization: Bearer <key>` when a key is configured, applies any extra headers (e.g., `Cache-Control`), sends the request, reads the `X-Forage-Cache` response header, decodes the JSON body into a generic map, and returns the decoded body plus cache status; verify with `httptest`-based tests in `client_test.go` covering: successful 200 response, non-2xx error response (asserts error includes status code and body), missing `X-Forage-Cache` header (asserts empty cache status), API key present/absent in `Authorization` header, `Cache-Control` header forwarded when provided
- [ ] 3.2 Implement a `Search(ctx context.Context, params SearchParams) (*SearchResult, error)` method on `ForageClient` that POSTs to `/search` with the query, limit, language, and engines fields, and returns a typed `SearchResult` struct; verify with `httptest` tests covering: valid response mapping (asserts `data.web` array is correctly decoded), empty results (asserts empty slice not nil), Forage 500 error (asserts error message includes HTTP status)
- [ ] 3.3 Implement an `Extract(ctx context.Context, params ExtractParams) (*ExtractResult, error)` method on `ForageClient` that POSTs to `/extract` with urls, formats, only_main_content, force_render, wait_for, timeout, engine fields, and returns a typed `ExtractResult` struct; verify with `httptest` tests covering: valid response mapping (asserts per-URL objects with url/title/content/raw_content/method are decoded), Forage 400 error (asserts error includes status code), context cancellation (asserts error indicates timeout when ctx is cancelled)
